# Chinmaya.Lab

A personal developer lab built with Next.js, TypeScript, and Tailwind CSS.

## ✨ Features

- Next.js App Router
- TypeScript
- Tailwind CSS
- SEO Ready
- Responsive Design
- Clean Folder Structure

## 🚀 Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000

## 📁 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
